
### 사이트 이름
사이트 이름을 SEISTAY로 변경해줘.

### 로그인 기능



로그인 페이지에는 다음을 넣어줘.

* 이메일 입력
* 비밀번호 입력
* 로그인 버튼
* 회원가입 페이지로 이동하는 버튼
* 로그인 실패 시 오류 메시지

로그인에 성공하면 **홈 페이지로 이동**하도록 해줘.

### 회원가입 기능

회원가입 페이지를 만들어줘.

입력 항목:

* 이름
* 이메일
* 비밀번호
* 비밀번호 확인


비밀번호가 일치하지 않으면 회원가입되지 않도록 하고 오류 메시지를 보여줘.

회원가입이 완료되면 로그인할 수 있도록 안내해줘.

### 로그인 상태

로그인한 사용자는 Header에서

**로그인 / 회원가입**

대신

**내 예약 | 마이페이지 | 로그아웃**

이 보이도록 해줘.

로그아웃을 누르면 로그아웃 처리 후 홈 페이지로 이동시켜줘.

로그인하지 않은 사용자가 예약하기 버튼을 누르면 로그인 페이지로 이동시키고,

"예약하려면 로그인이 필요합니다."

라는 안내를 보여줘.



### 중요한 사항

기존에 만들어진 숙소 목록, 숙소 상세, 검색 기능 등의 코드를 삭제하거나 변경하지 않는다.

로그인 기능에 필요한 파일만 추가하거나 수정한다.
